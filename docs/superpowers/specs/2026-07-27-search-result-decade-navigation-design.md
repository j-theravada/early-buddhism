# 検索結果の年代ナビゲーション 設計仕様

## 目的

動画一覧を検索・分類で絞り込んだ時も、結果に含まれる年代と件数を確認し、検索条件を保ったまま各年代の先頭へ移動できるようにする。

## 成功条件

- 検索結果に複数の年代がある場合、該当する年代だけを年代ナビに表示する。
- 各年代の件数は、検索・分類条件を適用した全結果の件数と一致する。
- 年代リンクは、検索語、検索対象、分類、シリーズを維持する。
- 年代の先頭が別ページにある場合、そのページの年代セクションへ移動する。
- 絞り込みがない動画一覧の年代ナビは、現在の挙動を維持する。

## 設計

`buildTalkListingPage()` で検索・分類条件を適用した `filteredItems` を年代別に集計し、`decadeTargets` を作る。各年代のページ番号は、絞り込み後の並び順と30件単位のページサイズから求める。

`DecadeJumpNav` には現在の一覧条件を渡す。年代リンクは `buildTalksHref()` にページ番号と現在の検索条件を渡して組み立て、年代セクションのアンカーを付ける。

```text
全動画
  -> 検索・分類条件を適用
  -> 絞り込み後の全結果を年代別に集計
  -> 年代ごとの件数・先頭ページ・アンカーを生成
  -> 現在の検索条件を保った年代リンクを表示
```

年代が0件または1種類だけの場合は、既存の `DecadeJumpNav` と同様に年代ナビを表示しない。

## 変更対象

- `app/application/talk/listing.ts`
  - 絞り込み後の全結果から `decadeTargets` を生成する。
- `app/components/talk-gallery/decade-jump-nav.tsx`
  - 現在の検索条件を受け取り、年代リンクへ引き継ぐ。
- `app/components/talk-listing.tsx`
  - `DecadeJumpNav` へ一覧条件を渡す。
- 対応するモデル・コンポーネントテスト

## 非対象

- 検索API、検索アルゴリズム、文字起こしスニペット生成は変更しない。
- 年代を新しい検索条件やURLパラメータとして追加しない。
- 年代ナビの見た目、表示位置、1ページ30件のページングは変更しない。
- `recordedOnDate` の古い順、日付なしを末尾とする並び順は変更しない。

## テスト

すべての挙動変更は、失敗するテストを先に追加してから実装する。

- 検索結果の全件から年代別の件数と先頭ページを生成する。
- 検索語、検索対象、分類、シリーズを含む年代リンクを生成する。
- 絞り込みなしの年代リンクとアンカーが従来どおりである。
- 対象テスト、全テスト、フォーマット、Lint、production buildを実行する。
